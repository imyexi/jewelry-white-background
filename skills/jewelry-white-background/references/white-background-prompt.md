# 背景 Mask Edit 固定 Prompt

## 权威来源与边界

`scripts/build_white_background_prompt.py` 是模型提示词的唯一构建入口。运行时必须通过该脚本生成 Prompt，不得手写、改造或替换模型提示词。

- 产品名称、产品参数、生肖或材料名称不得进入 Prompt。
- 只使用首张正面图，不读取或提交其他图片。
- 请求固定为单 image、单 mask，二者尺寸必须相同。
- Mask 透明区域是背景编辑区；Mask 之外的产品区域不得重绘。
- Prompt 只定义编辑目标，不输出内容、构图、占比或尺寸 QC。

脚本输出必须与下列代码块规范化后逐字一致，标题、顺序、标点和措辞都不得改变：

```text
【任务目标】
将图片 1 的透明背景区域编辑为连续、干净的浅白商品图背景。

【参考图职责】
- 图片 1 是唯一 Edit 底图，不作为创建新产品的参考。
- 只编辑 Mask 透明背景区域，不使用其他图片补充或替换内容。

【产品结构】
- Mask 不透明的产品区域不得重绘、移动、增删或替换。
- 保持所有珠子、串线、特殊件及其原有连接关系不变。

【材质细节】
- 保持产品区域的原始颜色、透明度、纹理、反光和可见细节不变。
- 不润饰、不扩写、不设计任何产品内容。

【背景、光线与阴影】
- 将透明背景区域填充为均匀的 #FBFCF9 浅白背景。
- 背景必须连续延伸到画布四边和四角，过渡自然且无接缝。
- 产品区域的原有光线、反光和阴影保持不变。

【构图】
- 保持原画布、原比例以及产品原有位置、尺寸和视角。
- 不裁切、不旋转、不缩放、不平移产品，也不改变画布边界。

【画面范围】
- 背景不得出现黑色外围、深色外围、暗角、边框或圆形背景块。
- 不添加道具、文字、标识或其他元素。
```
