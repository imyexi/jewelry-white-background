# 珠宝手串白底图 V2 提示词契约

## 用途

此文件定义模型可执行的 V2 提示词结构。先完成 `reference_plan.json` 校验，再用 `scripts/build_white_background_prompt.py` 生成最终文本。画幅和分辨率由 Yuan Image Generation v4 的 Wawapi Generation 请求参数设置，不重复写进模型提示词。

提示词只承载产品事实和视觉目标；文件路径、产品参数原文、任务编号、审计记录、历史失败描述和水印信息留在旁路文件中。

## 参考计划必须提供的事实

- 正面图：唯一的整体结构依据。
- 细节图：仅用于补充局部材质。
- 结构说明：珠子顺序、串线和逐项核对后的特殊件。
- 材质观察：每条记录在参考计划中带有一个可追溯的 `source_image`，只描述该图局部可见的颜色、通透程度、内含物、纹理走向、密度和明暗关系；图片路径不写入模型提示词。
- 构图阈值：产品宽度、居中偏差和完整呈现要求。
- 人工复核项：结构、材质和水印的最终检查清单。

## 固定提示词模板

模型提示词只能使用以下七段，按此顺序拼装。没有特殊件或定向纠偏时，保留标题并用正面图事实描述该段，不增加新的标题。

```text
【任务目标】
生成同一条真实珠宝手串的电商白底商品图，忠实呈现参考图中的具体产品。

【参考图职责】
- 第 1 张正面图只决定产品结构：珠子数量、顺序、串线、颜色、特殊件及相对位置。
- 正面图不决定白底画面的景别、产品占比或留白；白底画面的景别、产品占比和留白以【构图】为准。
- 后续细节图只补充局部材质，不改变产品结构。

【产品结构】
- <正面图中的珠子顺序和相对位置>
- <正面图中可见的串线>
- 必须保留：<单个、可在参考图中核对的特殊件>（位置：<位置>；<轮廓、材质或连接事实>）。

【材质细节】
- <材质主体>：<参考图局部可见的纹理、通透程度和明暗关系>。

【背景、光线与阴影】
- 背景为无缝 #FBFCF9 哑光米白纸质表面，纹理低对比、干净、均匀。
- 使用左上方 45 度柔和自然光和中低曝光，保留原图可见的色彩与内部层次。
- 产品自然放置在纸面上，每颗珠子和特殊件保留柔和、可见的接触阴影。

【构图】
- 产品居中、完整呈现，不裁切任何珠子或特殊件。
- 重新安排白底商品图的景别，以完整手串外接宽度和本段占比为准。
- 先建立产品宽度为 45%-55% 的白底构图，再根据正面图重建手串。
- 左右干净留白分别约为 22.5%-27.5%。
- 产品整体宽度占画面宽度的 45%-55%，保留均衡留白。

【画面范围】
- 画面只保留手串本体及其自然接触阴影。
- 不出现文字、标识、边框或额外道具。
```

## 组装规则

- 正面图只提供产品结构，不提供产品在白底画面中的景别、留白或占比。
- 细节图只追加到 `【材质细节】`，不能改变 `【产品结构】` 中的事实；任何结构字段出现“细节图”或“局部图”即为无效计划。
- 特殊件逐项填写可见实物名称、位置和外观事实；没有可见特殊件时，用正面图的结构事实完成该段。
- 原始产品参数仅供人工整理参考计划，不能直接拼入模型提示词。
- 定向纠偏按类型归入 `【产品结构】` 或 `【材质细节】`，每类最多三条，描述可观察的成功标准；材质纠偏不得新增、删除或重排任何产品结构。
- 所有填入提示词的事实必须是单行文本，不能含标题符号或渲染参数，避免生成额外段落或覆盖 Yuan v4 请求参数职责。

## SY1462 材质观察示例

```text
【产品结构】
- 必须保留：合金牛造型珠（位置：正面图左侧中部；金色金属造型、雕刻轮廓与中心深色圆形镶嵌均以正面图为准）。

【材质细节】
- 黄塔晶、绿幽灵和闪灵钻珠：分别以参考图中对应珠子的局部可见纹理为准，逐颗保留其底色、通透程度、内含物形态、纹理走向与密度，以及原图可见的明暗关系。
```

## 交付前检查

- 先校验 `reference_plan.json`，再构建提示词。
- 生图后先做水印前 QC；结构、逐颗材质和特殊件由人工核对。
- 水印后忽略水印区域再次检查构图，并记录双阶段 QC。
- 只有显式获得飞书追加授权且审计允许时，才可进入上传步骤。
